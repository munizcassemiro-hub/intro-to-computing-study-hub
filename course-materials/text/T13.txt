[SLIDE 3]
The printed circuit board (PCB) that holds and connects all the computer’s subsystems
Motherboard


[SLIDE 4]
Central Processing Unit
Executes the instructions in a programme.
Can perform basic arithmetic, logic, controlling and I/O operations.
The CPU chip can have more than one CPU “core”, so more work can be done at once.
It is also made up of other subsystems.
CPU


[SLIDE 5]
Graphic processing unit.
Specialised unit that is efficient at computer graphics and image processing.
Can process many things in parallel (at the same time).
Can have GPUs integrated into the CPU.
GPU


[SLIDE 6]
Random Access Memory
Data can be read and changed in any order, in the same amount of time.
Is generally volatile: stored information is lost if power is lost.
RAM


[SLIDE 7]
Where data can be stored in the long term.
Hard Disk Drive 
Uses magnetic storage on rotating platters to store data. 
Magnetic heads can then read the data.
Solid State Drive
Uses flash memory, like on USB drives.
Generally faster (higher data-transfer rates).
SATA – Serial AT Attachment
The drives are connected to the motherboard via  a bus cable.
NVMe – Non Volatile Memory Express
The drive is placed on the motherboard
Hard Drive
